AJAX 用户登录 Demo

JavaWeb + Servlet + 原生 AJAX，不刷新页面完成登录

功能

  • 登录表单用 AJAX 提交，页面不刷新
  • Servlet 返回 JSON：{"success":true,"message":"..."}
  • 用户名不存在 / 密码错误 / 参数为空 都有对应提示

测试账号

admin / 123456　　student / 123456

访问顺序

1. 打开 login.html（登录页面）
2. 用测试账号点「登录」，观察提示与页面变化

文件结构

src/main/java/com/pzy/
    model/User.java          用户实体
    store/UserStore.java     用户仓库（内存 Map 当数据库）
    web/LoginServlet.java    登录 Servlet，返回 JSON
src/main/webapp/
    login.html               登录页面（AJAX 在这）
    index.html               本说明页
    css/style.css            页面样式
    WEB-INF/web.xml          欢迎页 + 中文编码配置
